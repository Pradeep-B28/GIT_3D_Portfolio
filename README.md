> [!NOTE]
> **git-viz** fetches live GitHub user data and commit histories via REST API and constructs real-time 3D environments with WASD flight controls, custom GLSL shaders, procedural buildings, and generative synth soundscapes.

---

## 🏙️ 4 Interactive 3D Modes

1. 🏢 **3D City Skyline**: Contribution counts rendered as glowing skyscrapers; color-coded by language frequency.
2. 🪐 **Orbital Repo Galaxy**: Projects floating as celestial planets orbiting the developer's core star.
3. 🏝️ **Tech Archipelago**: Island archipelagos representing different tech stacks and frameworks.
4. ⚔️ **Developer Duel Arena**: Compare two GitHub usernames side-by-side in a 3D battle visualization!

---

## 🕹️ WASD Drone Flight Controls

- `W / A / S / D`: Pitch & Yaw Flight Navigation
- `Space / Shift`: Elevate Up / Lower Down
- `Mouse Drag`: 360° Free Camera Orbit

---

## 🚀 Quick Start

No build tools required! Simply serve the static directory:

```bash
# Clone the repository
git clone https://github.com/Pradeep-B28/GIT_3D_Portfolio.git
cd GIT_3D_Portfolio

# Launch local server using Python or npx
python -m http.server 8080

# Open browser at http://localhost:8080
```
